# SPAF-SegNeXt
  This work addresses key challenges including the loss of fine-grained boundary details, insufficient information from unimodal data, and poor cross-scene generalization capability in the remote sensing semantic segmentation of sugarcane planting areas across the complex karst landforms of Guangxi, China. To this end, we propose the Sugarcane Prior-guided Attention & Frequency-fused SegNeXt (SPAF-SegNeXt), establishing a hybrid multimodal semantic segmentation framework characterized by a three-stage pipeline: threshold prior guidance, frequency-domain feature fusion, and refined segmentation. Specifically, the proposed SugarPriorAM module incorporates threshold-based prior knowledge to achieve attention-guided feature optimization, which adaptively enhances the feature weights of sugarcane targets to suppress interference from complex backgrounds. Meanwhile, the FreqFusion module leverages a joint wavelet and Fourier transform to compensate for high-frequency boundary features, enabling precise reconstruction of fine-grained edge information for fragmented field parcels. The synergistic integration of these two modules enables end-to-end optimization from feature enhancement to precise segmentation, systematically resolving the core technical limitations of sugarcane remote sensing segmentation in complex karst scenarios.
  The accompanying submission files include the core implementation code for the proposed SPAF-SegNeXt model. Should this manuscript be accepted for publication, we will publicly release the complete end-to-end source code, model training configuration files, and pre-trained weights of the SPAF-SegNeXt model via GitHub, to ensure full reproducibility of the experimental results and strict adherence to the journal’s requirements and commitments regarding open science and transparent research practices.
  Furthermore, to address the critical gap in multimodal datasets for sugarcane remote sensing segmentation, we developed a novel multimodal sugarcane dataset, the Sugarcane Augmented Remote-sensing Fusion with Topographic Prior Dataset (SugarARF-Topo), which integrates both spectral and topographic information to provide high-quality data support for accurate sugarcane mapping in complex topographic environments. The version of the SugarARF-Topo dataset used in this work is currently available for download via Baidu Netdisk at the following link: ( https://pan.baidu.com/s/17Zf6jqHmaftFNZ_a9eDYpQ  Extraction code: afan). Upon formal publication of this manuscript, we will continue to optimize and expand this dataset in subsequent work, with incremental coverage of imagery from additional major sugarcane-producing provinces, diverse planting regimes, and the full growth cycle of sugarcane. These updates will further enhance the authority and generalizability of the dataset, providing a standardized benchmark for methodological innovation and validation in the field of fine-grained remote sensing interpretation of sugarcane.
