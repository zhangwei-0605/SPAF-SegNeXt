# SPAF-SegNeXt
Our study addresses three key challenges in remote sensing segmentation of sugarcane cultivation areas: the loss of high-frequency edge information in traditional segmentation models, the inability of single optical modalities to capture spectral-topographic coupling, and the lack of multimodal, large-scale remote sensing datasets for complex terrain validation. To address these, we propose SPAF-SegNeXt, a novel hybrid segmentation framework that incorporates the SugarPriorAM module for remote sensing cross-modal feature optimization and the FreqFusion module for high-frequency detail recovery in remote sensing images. We also introduce the SugarARF-Topo dataset, which bridges the gap in multimodal remote sensing data for sugarcane segmentation. Should this manuscript be accepted for publication in your esteemed journal, both the SugarARF-Topo dataset and the SPAF-SegNeXt source code will be publicly released via GitHub to ensure the full reproducibility of our experimental results, in strict accordance with the journal’s commitment to open science and transparent research practices.
